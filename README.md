#  Personal Expense Tracker

A clean, responsive, and user-friendly web application for tracking personal finances. Built entirely with  web technologies (HTML, CSS, and JavaScript), this project utilizes the browser's Local Storage to persist data seamlessly without requiring a backend database.

# Features

* **Dashboard Overview:** Instantly view your current balance, total income, and total expenses through dynamic summary cards.
* **Transaction Management (CRUD):** Easily add, edit, and delete income and expense records.
* **Categorization:** Assign categories to transactions (e.g., Food, Rent, Salary) for detailed tracking.
* **Dynamic Filtering:** Filter your transaction history by specific categories to analyze spending habits.
* **Data Persistence:** Transactions are saved locally in the browser, ensuring your financial data remains intact across different sessions.
* **Responsive Design:** Fully optimized layout that adapts perfectly to both desktop monitors and mobile screens.

## 🛠️ Technologies Used

* **HTML5:** Semantic structure and form handling.
* **CSS3:** Custom styling, CSS Grid and Flexbox for layout management, and responsive media queries.
* **JavaScript (ES6+):** DOM manipulation, event handling, array filtering, and Local Storage integration.
